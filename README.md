# ClipDock

動画をMP4、音声をMP3として保存するWindows / macOSアプリです。

[公式サイト](https://clipdock-d6z.pages.dev/) · [使い方・ヘルプ](https://clipdock-d6z.pages.dev/help)

## はじめに

対応環境: **Windows 10 / 11（x64）**、**macOS 14以降（Appleシリコン / Intel）**。

### Windows

1. [公式サイト](https://clipdock-d6z.pages.dev/)からインストーラー（.exe）を取得し、起動中のClipDockを終了してから実行します。通知領域のClipDockアイコンを右クリックし、「ClipDockを終了」を選びます。管理者権限は不要です。
2. スタートメニューからClipDockを起動します。初回の起動時に保存エンジンを自動で取得するため、インターネット接続が必要です。
3. 「URLから保存」に動画ページや動画ファイルのURLを貼り付け、MP4またはMP3を選んで「保存」を押します。

**未署名版について:** Windowsが発行元を証明書で確認できず、警告が出る場合があります。公式サイトから取得したことを確認し、実行する場合はSmartScreenの「詳細情報」→「実行」を選びます。「実行」がない場合は中止し、保護機能を無効にせず端末の管理者に確認してください。

.NETやPythonの別途インストールは不要です。保存エンジンの更新は、アプリの起動時（サインイン時の自動起動を含む）に自動で確認します。通知領域で起動したままの間も、保存中でなければ1日に1回確認します。同じ版でファイルが正常なら再取得しません。取得に失敗したときは「保存エンジンを準備」が表示され、押すと取得し直します。旧版からの更新直後やファイルが壊れている場合は、一度取得し直すことがあります。

ZIP版を使う場合だけ、すべて展開して `INSTALL.cmd` を開いてください。ポータブル利用では、展開先の `ClipDock.exe` を起動します。

### 通知領域とサインイン時の起動（Windows）

Windows版は初期設定で、Windowsへのサインイン時に通知領域で起動します。ウィンドウは開かず、保存エンジンの更新確認だけを行います。アイコンは初め、タスクバーの「^」で開く隠れたインジケーターに入ります。常に表示する場合は、Windowsのタスクバー設定でClipDockのアイコンをONにします。

- 通知領域のアイコンをクリックするか、スタートメニューからClipDockを起動すると、ウィンドウが開きます。
- ウィンドウの閉じるボタンを押しても終了しません。保存中の動画は通知領域で続きます。初めて閉じたときだけ、その旨を通知します。
- 終了するには、アイコンを右クリックして「ClipDockを終了」を選びます。保存中やエンジンの初回取得中は中断確認が出ます。
- 自動起動は左下の「Windowsの起動時に開始」で切り替えます。現在のユーザーのスタートアップ（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` の `ClipDock`）に登録するため、管理者権限は不要です。インストール先を移した場合は、次の起動時に登録先を更新します。
- Windowsの「設定」→「アプリ」→「スタートアップ」やタスクマネージャーでOFFにした場合は、その設定を優先します。ClipDock側の表示もOFFになり、ClipDockでONにし直すとWindows側もONに戻ります。

### macOS

macOS版は同じ保存処理を使う別ビルドです。[公式サイト](https://clipdock-d6z.pages.dev/)から、Appleシリコン用（`arm64`）またはIntel用（`x64`）のディスクイメージ（.dmg）を取得できます。

1. お使いのMacに合うディスクイメージを開きます。Appleシリコンは `arm64`、Intelは `x64` です。
2. `ClipDock` を「アプリケーション」フォルダーへドラッグし、そこから起動します。更新するときは、先にメニューバーのClipDockアイコンから「ClipDockを終了」を選びます。
3. 初回の起動時に保存エンジンを自動で取得します。インターネット接続が必要です。以降の使い方はWindows版と同じです。

**未署名版について:** macOS版にはApple Developer IDの署名と公証がありません。初回の起動時に、macOSが開発元を確認できないという警告を表示します。入手元を確認したうえで開く場合は、いったん警告を閉じ、「システム設定」→「プライバシーとセキュリティ」の「このまま開く」を選びます。この項目が出ない場合や入手元を確認できない場合は中止してください。Gatekeeperを無効にする必要はありません。

### メニューバーとログイン時の起動（macOS）

Mac版は初期設定で、Macへのログイン時にメニューバーで起動します。ウィンドウもDockのアイコンも開かず、保存エンジンの更新確認だけを行います。メニューバーで起動したままの間も、保存中でなければ1日に1回確認します。

- メニューバーのClipDockアイコン（トレイに向かう矢印）をクリックし、「ClipDockを開く」を選ぶとウィンドウが開きます。Finder・Launchpad・SpotlightからClipDockを開いても同じです。
- ウィンドウの閉じるボタン（⌘W）を押しても終了しません。ウィンドウとDockのアイコンが消え、保存中の動画はメニューバーで続きます。初めて閉じたときだけ、その旨を表示します。
- 終了するには、アイコンのメニューから「ClipDockを終了」を選ぶか、ウィンドウを開いて⌘Qを押します。保存中やエンジンの初回取得中は中断確認が出ます。
- 自動起動は左下の「ログイン時に開く」で切り替えます。現在のユーザーのLaunchAgent（`~/Library/LaunchAgents/app.clipdock.ClipDock.plist`）を作成し、`ClipDock.app` を `--background` 付きで起動します。管理者権限は不要です。作成したとき、macOSが「バックグラウンド項目が追加されました」と通知します。ClipDockを別の場所へ移した場合は、次の起動時に登録先を更新します。
- ディスクイメージから直接開いたClipDockは登録しません。「アプリケーション」フォルダーへ移してから開いてください。
- 「システム設定」→「一般」→「ログイン項目」（macOS 15以降は「ログイン項目と機能拡張」）の「バックグラウンドでの実行を許可」でOFFにした場合は、その設定を優先します。ClipDockはmacOS側の設定を変更しないため、ClipDock側の「ログイン時に開く」がONのままでも起動しません。もう一度使うときは、同じ画面でONにします。
- 「ログイン時に開く」がONの間は、ログアウト時の「再ログイン時にウインドウを再度開く」でClipDockのウィンドウが開くことはありません。

Windows版との違い:

- 「ブラウザー上部に保存タブ」はありません。URLは貼り付けるか、ログイン画面の「このページを取り込む」で渡します。
- ログイン画面はmacOS標準のWebKitを使います。WebView2は不要で、Safari・Chromeのログインとは別です。
- 「ログイン情報を削除」は、ClipDock内の全サイトのCookieを削除します。
- 「場所」はFinderでファイルを表示します。

## アプリの自動アップデート

ClipDockは、起動時と、起動したままの間は1日に1回、公式サイトの更新情報（`https://clipdock-d6z.pages.dev/updates/latest.json`）を確認します。新しいバージョンがあれば、バックグラウンドでダウンロードし、サイズとSHA-256が更新情報と一致することを確かめます。一致しないファイルは使わずに削除します。

- インストールは自動です。保存中・待機中の動画がなく、ウィンドウを閉じて通知領域（Mac版はメニューバー）にあるときに、ClipDockを終了して更新し、もう一度起動します。
- ウィンドウを開いている間は、左下に「再起動して ClipDock <バージョン> に更新」が表示されます。押すとすぐに更新します。保存中の場合は、保存が終わってから更新します。
- Windows版はインストーラーを確認画面なしで実行します。インストールできなかった場合は、元のバージョンをもう一度起動します。
- Mac版はディスクイメージ内の `ClipDock.app` のバージョンとバンドルIDを確かめてから、今の `ClipDock.app` と入れ替えます。途中で失敗した場合は元のアプリに戻します。
- 更新後に起動したとき、更新したことを一度だけ表示します。
- 自動アップデートするのはインストールしたClipDockだけです。WindowsのZIPから展開してそのまま使う場合、Macでディスクイメージから直接開いた場合、書き込みできない場所に置いた場合は、公式サイトから手動で更新してください。
- 自動アップデートは、この仕組みを含むバージョンから使えます。それより前のバージョン（1.0.4以前）は、一度だけ公式サイトから手動で更新してください。

ClipDockにはコード署名がないため、更新が本物かどうかは、公式サイトからHTTPSで取得した更新情報とSHA-256の一致で確かめます。

## 表示言語

1.0.4から、Windows版・Mac版の左下にある「言語（次回起動から適用）」で日本語・English・简体中文・Españolを選べます。選択は設定ファイルに保存し、アプリを閉じて開き直すと反映します。言語の変更だけでは進行中の保存を中断しません。初期設定は日本語です。以下では日本語の操作名を使います。OS標準のダイアログ、外部サイト、保存エンジンの生の診断や既存履歴の説明は元の言語で表示される場合があります。

## 使い方

形式の初期値はMP4です。MP3は音声のみを保存します。形式・画質・保存先の選択は次回も保持します。初期保存先はWindows・macOSともダウンロードフォルダー内の `ClipDock` です。「保存先を変更」で選び直せます。変更は、その後に保存する項目へ適用されます。

MP4の画質は最高画質／2160p／1080p／720p／480pから選べます。4K / 2160pも解像度の上限で、元の配信が1080pまでなら1080pになります。低解像度の動画を4Kに拡大する機能はありません。

初期設定では**2件を同時に保存**します。「同時保存」で1〜4件に変更でき、次回起動時にも保持します。変換中も同時保存数に含みます。件数を減らしても進行中の保存は中断せず、空きができるまで新しい項目を待機させます。

動画と音声が別配信でも、全体を1件の進捗で表示します。取得・変換は95%まで進み、完成ファイルの確認が終わると100%になります。**「保存完了」になるまで待ってください**。完了後は「開く」で再生、「場所」でファイルのあるフォルダーを開けます。

MP4はコンテナ形式で、元の映像コーデックを保持することがあります。画質は解像度を優先し、同じ解像度ならH.264 / AACを優先します。4Kや最高画質ではVP9やAV1になる場合があります。再生できない機器向けには1080p以下も試してください。

キャンセル後の「再試行」は取得済みの断片からの再開を試みます。サイトや期限付きURLによっては最初から取得し直すため、新しいURLの追加が必要になることもあります。Windows版・Mac版とも、ウィンドウを閉じても保存を続けます。処理中にアプリを終了すると中断確認が出ます。再起動後に中断された項目が勝手に再開されることはありません。

## ブラウザー上部の保存タブ

Windows版の機能です。「ブラウザー上部に保存タブ」は初期状態でOFFです。ONにすると、前面のChrome・Edgeの上中央にマウスを合わせて「ClipDockに取り込む」を使えます。読み取ったURLはアプリの入力欄に入るため、内容を確認して「保存」を押してください。取り込みだけでは保存を開始しません。

アドレスを編集中の場合や読み取れない場合は、URLを手動で貼り付けてください。表示で省略された `https://` が補われる場合もあるため、取り込んだURLを確認してください。このURL取り込みはChrome・EdgeのCookieやログイン情報を読み出しません。保存時の認証には、アプリ内のログイン設定を使います。

## ログインが必要な動画

「この保存にログイン情報を使う」は初期ONで、変更した設定も保持します。初回は「ログイン」を押し、ClipDock専用の画面で保存対象のサイトへサインインしてください。ChromeやEdgeの既存ログインとは別です。Windows版のログイン画面には [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) が必要です。見つからない場合はMicrosoft公式の案内から導入します。

保存開始・再試行ごとに、専用画面の対象サイトのCookieを確認して利用します。OFFにすると次の保存・再試行でCookieをエンジンへ渡しません。動画の削除・公開条件・サイト制限によっては、ログインしていても保存できない場合があります。

Windows版の「ログイン情報を削除」は、ClipDock専用プロファイルにある全サイトのログイン情報と閲覧データを消去します。Mac版では全サイトのCookieを削除します。進行中の保存があれば、完了またはキャンセルしてから実行してください。Cookieを保存履歴に残さず、処理用の一時ファイルは終了時に削除します。専用プロファイルの保持と削除の詳細はプライバシーポリシーを参照してください。

## 対応範囲

- HTTP(S)の動画・ページURL、保存エンジンの対応サイト、非DRMのHLS/DASHが対象です。
- DRMの解除やアクセス制限の解除は行いません。サイトの変更・公開条件・認証方式によっては保存できません。
- ログインが必要な場合は、アプリ内の「ログイン」を使います。既存ブラウザーのログイン状態は引き継ぎません。
- `blob:` URLそのものは保存できません。動画があるページのHTTP(S) URLを指定してください。
- 再生中のライブ配信は終了まで長時間動作する場合があります。ライブの録画専用アプリではありません。
- ダウンロードする権利のある動画に利用してください。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 待機したまま | エンジンの取得中はキューが待機します。「保存エンジンを準備」が表示されていれば、通信環境を確認して押します |
| 403・ログイン要求・Xで動画が見つからない | 公開状態とURLを確認し、必要ならアプリの「ログイン」で接続してから再試行します。すべての投稿の取得を保証するものではありません |
| 対応サイトで失敗 | ClipDockを開き直すと、エンジンの更新を確認します。サイト自体の制約で取得できないこともあります |
| 保存タブが出ない・URLを読めない | Chrome・Edgeを前面に出して上中央へマウスを移動。読み取れなければURLを手動で貼り付けます |
| 変換中の表示が続く | 結合や再エンコードに時間がかかる場合があります。「保存完了」まで待ちます |
| 途中ファイルが残っている | 保存先の隠しフォルダー `.clipdock-work/<job-id>/` は再試行用です。「履歴を消去」で対象項目の作業ファイルも削除できます。完成ファイルは残します |

エラーの詳細は履歴内の説明にマウスを乗せると確認できます。

## 保存データ

Windows版では、ログイン用のCookie・閲覧データは専用の `browser-profile`、保存処理中の一時Cookieは `sessions` に保持します。設定は `%LOCALAPPDATA%\ClipDock\settings.json`、最大300件の履歴は同じ場所の `history.dat` に保存します。履歴はWindows DPAPIで暗号化します。更新したエンジンは `tools` に保存し、版数とSHA-256は `tools\versions.json` に記録します。

アプリは開発者への利用状況の送信やテレメトリーを行いません。保存時は動画の配信元と解析に必要なサイト、エンジンの準備・更新時はGitHub、公式サイトやインストーラーの取得時とアプリの更新確認・ダウンロード時はCloudflareへ接続します。詳細は [プライバシーポリシー](PRIVACY.md) を参照してください。

Windows版は通知領域のアイコンから「ClipDockを終了」で終了してから、Windowsの「設定」→「アプリ」からアンインストールできます。ZIP版はインストール先の `UNINSTALL.cmd` を使います。どちらも、そのインストールを起動するサインイン時の登録を削除します。保存ファイルと設定・履歴・ログイン用プロファイルは残るため、不要なら `%LOCALAPPDATA%\ClipDock` と保存先のファイル・残っている `.clipdock-work` を別途削除してください。

## 開発

日々の変更は、WindowsでもmacOS・Linuxでも数秒で確認できます（.NET 10 SDKとNode.js 22以降）。

```bash
npm run test:all                                        # 下の3つをまとめて実行
dotnet run --project tests/ClipDock.Checks -c Release   # アプリのチェック。Windows専用の項目は他のOSでSKIP
dotnet run --project tests/ClipDock.Checks -c Release -- --filter retry   # 名前に「retry」を含むチェックだけ
npm test                                                # ダウンロード関数と公式サイトの静的チェック
```

アプリのチェックは、保存一覧のルール（`DownloadLibrary`：重複・上限・再試行・履歴の復元・終了処理）、エンジン出力の解釈（yt-dlpの代わりのスクリプトで進捗・完成ファイルの確認・エラー内の署名付きURLとログイン情報の伏せ字・キャンセル）、保存処理の引数、ログイン情報、エンジン更新を対象とします。サイトのチェックは、全ページのダウンロードリンクとバージョン、内部リンクとアンカー、言語ごとのcanonical・hreflang、sitemap、Content-Security-Policyに反するインライン記述を確認します。失敗すると条件式と行番号を表示します。GitHub Actions（`.github/workflows/build.yml`）はpush・PRのたびに、アプリのチェックをLinux・Windows・macOSで実行し、失敗・SKIPした項目を実行ページのサマリーに表示します。WindowsとmacOSのジョブは、続けて実エンジンでの保存とパッケージ作成も行います。同じブランチへ新しくpushすると、実行中の古い確認は取り消されます（リリースタグは除く）。WindowsのWPF画面もmacOS・Linuxで `dotnet build ClipDock.slnx -c Release -p:EnableWindowsTargeting=true` によりビルドだけは確認できます。

Windows版のパッケージ作成に必要なもの: Windows、.NET 10 SDK、Node.js 22以降。

```powershell
.\scripts\build.ps1 -Zip

dotnet build ClipDock.slnx -c Release
dotnet run --project tests/ClipDock.Checks -c Release
npm test
npm run check

node scripts/smoke-downloads.mjs "$env:LOCALAPPDATA\ClipDock\tools"
```

生成先は `artifacts\ClipDock-win-x64` と `artifacts\ClipDock-win-x64.zip` です。インストーラーの作成・署名・検証は [配布手順](docs/distribution.md) を参照してください。

macOS版はmacOS上でビルドします（.NET 10 SDKが必要）。

```bash
bash scripts/build-mac.sh arm64   # または x64
bash scripts/test-mac.sh arm64    # 署名・ディスクイメージ・実エンジンでの保存・画面の自動確認
```

生成先は `artifacts/mac-<arch>/ClipDock.app` と `artifacts/mac/ClipDock-<version>-mac-<arch>-unsigned.dmg` です。画面はAvalonia製でWindowsでも起動できるため、`dotnet run --project src/ClipDock.Mac -- --data-dir <作業用フォルダー>` で見た目と操作を確認できます。`--data-dir` を付けた実行や `.app` に入っていない開発用ビルドは、ログイン時の起動設定（LaunchAgent）を変更しません。

構成は `ClipDock.App`（Windows用のWPFアプリ）、`ClipDock.Mac`（macOS用のAvaloniaアプリ）、`ClipDock.Core`（ダウンロード処理・設定・エンジン取得）です。UIに依存しない `ClipDock.App` の `DownloadItem.cs`・`DownloadEngine.cs`・`DownloadFailure.cs`・`DownloadLibrary.cs` はMac版とチェックでも共有します。保存一覧の振る舞いを変えるときは、両方の画面ではなく `DownloadLibrary` を変更します。実機での確認は [手動確認手順](docs/manual-checks.md) を使います。

macOS版では、設定・履歴・エンジンを `~/Library/Application Support/ClipDock` に保存します。macOSにはDPAPIがないため、履歴は暗号化せず、現在のユーザーだけが読み書きできるファイル（フォルダー700、ファイル600）として保存します。ログイン用のCookieはアプリ専用のWebKitデータに保持し、Safariとは共有しません。アンインストールは、左下の「ログイン時に開く」をOFFにし、メニューバーのアイコンから「ClipDockを終了」を選んでから、「アプリケーション」フォルダーの `ClipDock` をゴミ箱へ移します。先にゴミ箱へ移した場合は `~/Library/LaunchAgents/app.clipdock.ClipDock.plist` も削除してください。設定・履歴・保存ファイルは残ります。
