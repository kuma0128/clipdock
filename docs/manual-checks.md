# 手動確認手順

ダウンロードする権利のある動画で確認してください。

1. 標準ユーザーでEXE版をインストールして起動。ZIP版は `INSTALL.cmd` を使う。「保存エンジンを準備」で初回の取得を行う。
2. 公開MP4のURLを貼り付け、初期形式がMP4であることを確認して保存。動画と音声が別配信でも進捗は1つで、取得・変換は95%まで、完成ファイルの確認後に100%となる。元動画に音声があれば、保存ファイルでも再生できる。
3. 音声付き動画をMP3で保存し、音声を再生できる。MP3選択時は画質欄が無効になる。形式・画質の選択は再起動後も保持される。
4. 対応サイトのページURLと非DRMのHLS/DASHを保存。タイトル、形式、画質上限、保存先、ファイルを開く操作を確認する。
5. 「保存先を変更」で日本語・空白を含むフォルダーを選択。以後に追加する項目がそこへ保存され、「開く」でフォルダーが開く。再起動後も保持される。
6. 異なる動画を4件追加し、初期値2件で並列保存される。空きができると待機項目が順に開始する。変換中も同時保存数に含まれる。
7. 保存中の1件をキャンセル・再試行し、他の保存が継続する。保存先の隠しフォルダー `.clipdock-work/<job-id>/` に作業ファイルが保持され、再試行で使われる。完了時は作業フォルダーを削除し、保存先直下には完成ファイルのみが残る。待機中・開始直後のキャンセル、失敗後に次の項目が進むことも確認する。
8. 「同時保存」を2→4にすると待機項目が追加で始まる。4→1では進行中の項目を中断せず、以後の開始が空きを待つ。再起動後も選択を保持する。
9. 保存中にアプリを閉じると中断確認が出る。承諾すると全件停止し、保存エンジンの終了を待って閉じる。再起動後に未完了項目が勝手に再開しない。
10. DRM動画や取得不能URLがエラーになり、成功扱いされない。別の正常な動画は保存できる。エラー説明に認証情報を含むURLが表示されない。
11. 4K配信を2160p上限、同じ動画を1080p上限で保存する。1080pまでの動画を4K指定しても拡大されない。
12. 「すべて / ダウンロード中 / 保存したファイル」の絞り込み、完了後の「開く」「場所」、「履歴を消去」を確認。履歴を消すと対象項目の未完了作業ファイルも消え、完成した保存ファイルは残る。
13. エンジンの更新確認で、同じ版で整合性が確認できればバイナリを再取得しない。旧版に検証情報がない場合は一度取得し直し、次の確認では再取得しない。
14. エンジン取得中にアプリを閉じると中止確認が出る。終了後も既存エンジンが使え、不完全な取得を準備完了にしない。
15. 「ブラウザー上部に保存タブ」は初期OFF。ONにし、Chrome・Edgeを前面に出して上中央にマウスを合わせる。「ClipDockに取り込む」を押すとURL候補が入力され、確認して「追加」を押すまで保存は始まらない。
16. ブラウザーのアドレスが編集中・読み取り不能なら手動貼り付けを案内する。スキーム補完時は確認メッセージが出る。複数画面・異なる表示倍率・ウィンドウ移動後もタブ位置と取り込み先を確認する。
17. 保存タブをOFFにすると表示とウィンドウ情報の確認が停止する。このURL取り込み機能はブラウザーのCookie・ページ本文・閲覧履歴・クリップボードを読み取らない。
18. インストーラーで更新して設定・履歴を引き継ぐ。標準ユーザーでアンインストールし、アプリと所有するショートカットが消え、設定・履歴・保存ファイルは残ることを確認する。

19. 「この保存にログイン情報を使う」は設定ファイルがない場合も初期ONで、OFFの選択は再起動後も保持する。OFFで次に追加・再試行した要求はログインCookieを使わない。
20. 「ログイン」で専用画面を開く。Chrome・Edgeとは別のセッションで保存対象のサイトにサインインし、対象動画ページから「このページを取り込む」で主画面へURLを渡す。URL確認前に保存が始まらない。パスワード自動保存が無効である。
21. 許可されたテストアカウントと動画でログイン保存・再試行を確認。保存開始ごとに対象サイトのCookieのみを使い、別サイトのCookieを混ぜない。Cookie値は保存履歴・エラー表示に残さず、一時ファイルは完了・失敗・キャンセル後に削除する。異常終了で残ったものは次回起動で削除を試みる。
22. 「ログイン情報を削除」で専用画面の全サイトのログイン情報と閲覧データを削除する。進行中の保存がある間は削除できない。OFFだけではサインイン状態を削除しない。
23. WebView2 Runtimeがない環境でログイン画面を開くとMicrosoft公式の導入案内が出る。YouTubeのトップページ・検索結果では動画ページURLの案内となり、無関係な動画を保存しない。

問題を報告する場合は、操作内容、エラー説明、Windowsとブラウザーのバージョン、エンジンの `tools/versions.json` の版数を添えてください。認証情報や署名付きURLのクエリーは公開しないでください。
