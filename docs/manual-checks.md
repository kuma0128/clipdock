# 手動確認メモ

次の操作を、ダウンロードする権利のある動画で確認してください。下部に実施済みの検証を記録します。

1. `INSTALL.cmd` → Chromeにインストール先の拡張を読み込み → ポップアップに「接続済み」。アプリで「エンジンの準備完了」を確認。
2. 通常のMP4を表示するページを再読み込み。動画にマウスを乗せると保存ボタンが出る。保存するとアプリが起動し、音声付きMP4が再生できる。
3. 対応サイトの動画ページを「このページの動画を保存」から送信。タイトル、画質上限、保存先、ファイルを開く操作を確認。
4. 非DRMのHLS/DASHの動画を再生。検出一覧にマニフェストが出て、`.ts` / `.m4s`などの断片が大量に出ない。選択した動画が音声と結合される。
5. 「同時保存」が2件の状態で異なる動画を4件送信。2件が並列で進み、空きができたら待機中の動画が追加した順に始まる。同じ動画の連続クリックは実行中に重複登録されない。
6. 並列で保存中の1件をキャンセル→再試行。ほかの動画は進み続け、再試行した動画は待機列の最後から同じ出力識別子で再開を試みる。待機中のキャンセルや開始直後のキャンセルも確認。失敗した場合も次の動画が処理される。
7. 保存先を日本語・空白を含む別フォルダーに変更。以後の動画がその場所に保存される。
8. Cookieが必要なページではオプションをONにして許可。処理後に `%LOCALAPPDATA%\ClipDock\sessions` にCookieファイルが残らないことを確認。
9. ページ遷移・タブ終了で古い検出候補が消える。拡張のサービスワーカー停止後も再びアイコンを開けば通信できる。
10. アプリを閉じてから拡張で送信→アプリ起動。稼働中に再送信→二重ウィンドウにならない。
11. 複数のダウンロードと待機項目がある状態でアプリを閉じようとすると中断確認。承諾すると全件停止し、エンジンの終了とCookie削除を待って閉じる。再起動後、未完了の項目が勝手に再開しない。
12. DRM動画・取得不能URLではエラーになり、成功扱いしない。別の正常な動画を追加すれば処理できる。
13. 4K配信のある動画を「4K / 2160p」で保存し、1080pを超える解像度で保存される。同じ動画を1080pで保存するとH.264 / AACになる。
14. アプリ左の「すべて / ダウンロード中 / 保存した動画」を切り替えると選択中の項目に色が付く。保存完了の「場所」でファイルが選択された状態のフォルダーが開く。
15. `blob:` で再生する動画を右クリックしてもClipDockのメニューが出る。SPAサイトで別の動画へ移動すると検出一覧が入れ替わり、同じページ内の操作だけでは一覧が消えない。
16. エンジンの準備中にアプリを閉じると中止確認が出て、「はい」で終了できる。
17. インストール先の `UNINSTALL.cmd` をダブルクリック。フォルダー・ショートカット・Chrome連携の登録が消え、`%LOCALAPPDATA%\ClipDock` は残る。
18. CookieオプションをONにして1件送信した後、選択がOFFに戻る。送信失敗やページ移動後も、次の保存に同意が持ち越されない。
19. 動画ページから別ページへ移動中に古い動画の応答が到着しても、移動後の検出一覧には混ざらない。
20. 保存中に「同時保存」を2→4にすると待機項目が追加で始まる。4→1にすると進行中の項目は中断されず、新しい項目は空きを待つ。再起動して選択が保持されることを確認。

- Chrome拡張の実ブラウザーでの読み込みと実サイトでの保存は、上記の自動チェック・ローカル動画の検証とは別に確認が必要。

### 並列保存の追加検証

- .NETのチェックを33件に拡充。同時実行数、追加順、件数の変更、待機中・実行中の個別キャンセル、失敗後の継続、全件終了と後処理、開始前キャンセル、旧設定の読み込み、古い実行中の履歴保持を確認。
- `scripts/smoke-downloads.mjs` でローカルHTTP側から2件の同時転送を観測。MP4・WebM・HLSを保存し、404があっても後続の保存が完了。日本語・空白を含む保存先を使用。
- 実エンジンで1件のキャンセルがもう1件に影響しないこと、同じ識別子での再開、2件実行中と1件待機中の全件停止、テスト用Cookieの削除を確認。完成したすべてのMP4をffprobeで検査し、映像・音声ストリームを確認。
- このPCへ更新版をインストールし、既存の2件の履歴と保存先が引き継がれることを確認。「同時保存」の1〜4件の選択肢、4件への変更、再起動後の4件の表示を実画面で確認。画質と同時保存の選択欄・追加ボタンの文字色も修正し、読み取れることを確認。

問題を報告する場合は、操作内容、エラー説明、Chromeのバージョン、`tools/versions.json` のバージョン情報を添えてください。Cookie値や署名付きURLのクエリーは公開しないでください。
