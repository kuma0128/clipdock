## 短い説明

Chromeの動画をWindows用ClipDockアプリでMP4として保存します。別途Windowsアプリが必要です。YouTubeには対応していません。

## 詳しい説明

ClipDockは、Chromeで見つけた動画をWindowsアプリへ送り、MP4で保存する拡張機能です。Windows 10 / 11の64bit版に対応し、別途ClipDock本体のインストールが必要です。拡張機能だけでは動画を保存できません。

動画上の「MP4で保存」ボタン、拡張ポップアップ、右クリックメニューから保存を開始できます。MP4・HLS・DASHなどの検出候補を選び、画質の上限を指定できます。進捗の確認、保存先の変更、キャンセル・再試行はWindowsアプリで行います。

使い始めるには、下記の配布ページからWindowsアプリを入手してインストールし、「Chrome連携を設定」を実行してください。初回はアプリの「エンジンを準備 / 更新」で保存エンジンを取得します。

https://clipdock-d6z.pages.dev/

ログインが必要な動画では、「この保存にページのログイン情報を使う」を、その保存操作に限って選べます。CookieはPC内のアプリへ渡し、保存処理後に削除します。履歴には残しません。ページと動画のURL、タイトル、保存設定などは、動画の検出・保存のためにPC内で処理します。開発者への利用状況の送信や広告表示はありません。

YouTubeとDRM保護動画には対応していません。サイト側の変更、公開条件、認証方式によっては保存できない場合があります。ダウンロードする権利のある動画に利用してください。

## 単一目的

ユーザーが選んだウェブ動画を、PC内のClipDock Windowsアプリへ送り、MP4として保存できるようにすること。

## 権限の説明

| 権限 | 入力内容 |
| --- | --- |
| `storage` | 画質と保存ボタンの表示設定、およびタブごとの検出候補をPC内に保存します。候補は最大50件で、ページ遷移・タブ終了で消去します |
| `nativeMessaging` | ユーザーが選んだ保存要求をPC内のClipDock Windowsアプリへ渡し、接続状態を確認します |
| `webRequest` | 動画通信のURL、Content-Type、Content-LengthからMP4・HLS・DASHの保存候補を検出します。リクエストの書き換えやブロックは行いません |
| `webNavigation` | ページ・フレームの移動を識別し、古い動画候補や移動前のページからの保存要求が混ざらないようにします |
| `contextMenus` | 動画、リンク、ページの右クリックメニューにClipDockへの保存操作を追加します |
| `cookies`（任意） | ポップアップで利用を選んだ1回の保存について、ページと対象動画・フレームに対応するCookieを取得し、PC内のアプリへ渡します。通常の保存では読み取りません |
| `http://*/*`、`https://*/*` | ユーザーが閲覧するページの動画上に保存ボタンを表示し、ページとは別の配信ドメインを含むメディア通信を検出します。YouTube関連の保存対象はストア版で除外します |

## データ利用の申告

ローカル処理も申告対象です。「ユーザーデータを扱わない」とは申告しません。

| データ区分 | 該当する処理 |
| --- | --- |
| 認証情報 | 保存ごとに利用を選んだ認証Cookie |
| ウェブ履歴 | 開いているページ・フレーム・メディアのURLとページタイトル。Chrome全体の過去の閲覧履歴を読み取る機能はありません |
| ウェブサイトのコンテンツ | 動画のURL、形式、サイズ、ファイル名、タイトルと、保存する動画 |
| ユーザーのアクティビティ | 動画を検出するためのメディア通信の監視と、ページ遷移・動画再生状態の処理。キー入力やマウスの移動履歴は保存しません |

データの販売、単一目的と無関係な利用・転送、信用力や融資の判断への利用は行いません。申告内容と [プライバシーポリシー](../PRIVACY.md) を一致させて提出してください。

## リモートコード

拡張機能でリモートコードは使用しません。拡張で実行するJavaScriptとCSSはZIP内に含まれます。動画の取得・変換は、ユーザーが別途インストールしたWindowsアプリで行います。そのアプリは、保存エンジンをGitHubの配布元から取得・更新します。

## 掲載前の確認

プライバシーポリシーのURLが公開状態で開くこと、対応するWindowsアプリが配布されていること、ストアで発行された拡張IDとアプリの連携設定が一致していることを確認してから審査へ提出してください。ストアのカテゴリ、連絡先、デベロッパー情報は公開管理画面で実際の項目と登録内容に合わせて入力します。
