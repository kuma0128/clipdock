Installation

Windows

  1. Download the installer (.exe) from the official site.
  2. Quit ClipDock (right-click its notification-area icon and choose “Quit ClipDock”), then open the installer and follow its instructions. Administrator rights are not required.
  3. Open ClipDock from Start. The first launch downloads the download engine automatically and requires internet access.

Windows 10 or 11, 64-bit x64, is required. You do not need to install .NET or Python separately. For the ZIP package, extract all files and open INSTALL.cmd.

The app checks for engine updates when it starts and once a day while it keeps running. An unchanged, intact version is reused. Older installations or damaged files may require a one-time download of the same version. If a download fails, 「保存エンジンを準備」 (Prepare download engine) appears; click it to try again.

The login window requires Microsoft Edge WebView2 Runtime. If it is missing, use the Microsoft link in that window to install it.

Mac

  1. Download the disk image (.dmg) that matches your Mac from this site: arm64 for Apple silicon, x64 for Intel.
  2. Open the disk image and drag ClipDock to the Applications folder.
  3. Open it from Applications. The first launch downloads the download engine, which requires an internet connection.

macOS 14 or later is supported. The Login window uses the WebKit engine built into macOS, so nothing else needs to be installed. The optional tab above the browser is not available on Mac.

Running in the background

By default, ClipDock starts when you sign in to Windows (or log in to your Mac) and waits in the notification area on Windows or the menu bar on Mac. Closing the window does not quit it, and downloads keep running.

  • To open the window, click the notification-area icon (on Mac, choose “Open ClipDock” from the menu bar icon), or open ClipDock from Start or Applications.
  • To quit, right-click the icon (on Mac, use the icon's menu) and choose “Quit ClipDock”. If a download is running, ClipDock asks first.
  • Turn starting at sign-in on or off with “Start with Windows” (on Mac, “Open at login”) at the lower left. If you turn ClipDock off in Windows Settings → Apps → Startup or in the Mac's Login Items, that setting wins.
  • On Windows the icon first appears in the list behind the taskbar's “^” button. To keep it visible, turn ClipDock on in the taskbar settings.

Automatic app updates

ClipDock checks for a new version when it starts and once a day while it keeps running. A new version is downloaded in the background and used only when its size and SHA-256 match the update information on this site.

  • When nothing is being saved or queued and the window is closed to the notification area or menu bar, ClipDock updates itself and starts again.
  • While the window is open, “Restart to update to ClipDock …” appears at the lower left. Click it to update right away.
  • After updating, ClipDock says so once. Settings, history and saved files are kept.
  • If you use an earlier version without automatic updates, install the new version from this site once. A copy run straight from the extracted ZIP or opened directly from the Mac disk image does not update itself.

If Windows shows a warning

The installer is unsigned, so Windows cannot verify its publisher through a certificate. Check that the file came from this official site. Compare its SHA-256 with the value linked beside the download to confirm that the files match.

  1. If you have checked the source and choose to run it, select “More info” in SmartScreen.
  2. Select “Run anyway”.
  3. If that option is missing or you cannot verify the source, stop and ask the device administrator. Do not disable Windows protection.

A SHA-256 checksum verifies that files match. It is not a signature identifying the publisher.

If macOS shows a warning

The Mac version has no Apple Developer ID signature or notarization, so macOS cannot verify its developer. Check that you downloaded it from this official site. Comparing the file with the SHA-256 beside the download confirms it matches the published file.

  1. When the warning appears, close it.
  2. If you have confirmed the source and want to open the app, go to System Settings → Privacy & Security and choose “Open Anyway” for ClipDock.
  3. If that option is not shown, or you cannot confirm the source, stop. You do not need to turn off Gatekeeper.

Display language

Choose 日本語, English, 简体中文 or Español in Language (after restart) at the bottom left. Your choice is saved and applied when you close and reopen the app. Changing the language does not interrupt downloads. The instructions below use the Japanese control labels.

Save from a URL

  1. Copy a video page or media URL and paste it into 「URLから保存」.
  2. Choose a format. MP4 is the default; MP3 saves audio only.
  3. Choose a folder with 「保存先を変更」, then click 「保存」 (Save).
  4. Wait for 「保存完了」 (Saved). Use 「開く」 to open the file or 「場所」 to show its folder.

The default is ClipDock inside Downloads on Windows and Mac. Folder changes apply to jobs added afterward. Format, quality and destination choices are retained.

The default is two simultaneous jobs, adjustable from one to four. Conversion counts as an active job. Reducing the limit does not interrupt running jobs.

Quality and file formats

MP4 saves video; MP3 saves audio only. The quality field is disabled for MP3.

480p, 720p, 1080p and 4K are maximum resolutions. A 1080p source is not enlarged to 4K. “Best available” cannot improve on the source stream.

Separate audio and video streams share one progress indicator. Downloading and conversion advance to 95%; the job reaches 100% after the finished file is verified. The completed MP4 or MP3 is placed in your destination folder. MP4 may retain the source codec; if a device cannot play it, trying 1080p or lower may help.

Videos that require a login

「この保存にログイン情報を使う」 (Use login information for this download) is on by default, and your choice is retained. Click 「ログイン」 and sign in to the site you want to save from in ClipDock's dedicated window. This session is separate from Chrome and Edge.

Use 「このページを取り込む」 to place the video's URL in the main window, review it, and click 「保存」.

The app uses cookies for the target site when a download or retry starts. Turning the option off prevents cookies being passed to the next added or retried job. It does not sign you out of the login window.

「ログイン情報を削除」 clears login and browsing data for all sites in the dedicated profile. Finish or cancel active jobs first. Cookie values are not included in download history; temporary cookie files are deleted after processing.

Password autosave is disabled. Site restrictions and post availability can still prevent downloads even when you are signed in.

Optional tab above the browser

This is a Windows feature. It is not available on Mac.

「ブラウザー上部に保存タブ」 is off by default. When enabled, it can try to import a URL from Chrome or Edge.

  1. Bring Chrome or Edge to the front and move the pointer to the top center of its window.
  2. Click 「ClipDockに取り込む」 (Import to ClipDock).
  3. Check the address placed in the app, then click 「保存」. Importing alone does not start a download.

If the address is being edited or cannot be read, paste it manually. An omitted https:// may be added, so always review the URL. This feature does not read cookies, login information, page content or browsing history.

After importing a URL, the app's login-information setting applies to the download.

Troubleshooting

403, a login request, or no video found on X
Check the URL and availability. If needed, sign in to the site you want to save from through the app's 「ログイン」 window, then retry. Existing browser sessions are not imported. Site restrictions may still prevent a download.
A job stays queued
The queue waits while the download engine is being installed. If 「保存エンジンを準備」 (Prepare download engine) is shown, check your connection and click it.
A supported site fails
ClipDock checks for engine updates when it starts and once a day. To check right away, quit ClipDock and open it again. Site changes or restrictions may still prevent a download.
Files remain after cancellation
Download and conversion files are kept in the hidden .clipdock-work/<job-id>/ folder inside your destination. It is removed after success. Cancellation, failure or closing the app keeps it for retry. Clear history also removes unfinished work files for those records; completed media is kept.

ClipDock does not remove DRM or bypass access restrictions. A blob: URL cannot be used directly; use the HTTP(S) URL of the video page. A live stream may keep running until the broadcast ends.

Delete history or uninstall

「履歴を消去」 clears completed, failed and cancelled records, along with any unfinished work files for those jobs. It does not delete completed media or login information.

Quit ClipDock from its notification-area icon, then uninstall it in Windows Settings → Apps. For the ZIP package, use UNINSTALL.cmd in its installation folder. Both remove the start-at-sign-in entry.

Settings, history and saved files remain. To remove all app data, quit ClipDock and delete %LOCALAPPDATA%\ClipDock and any saved files you no longer need.

The login profile also remains after uninstalling. To clear only login information, use 「ログイン情報を削除」 in the dedicated login window.

On Mac, choose “Quit ClipDock” from the menu bar icon and move ClipDock from the Applications folder to the Trash. Settings, history and login data remain in ~/Library/Application Support/ClipDock and ~/Library/WebKit/app.clipdock.ClipDock. The login item file ~/Library/LaunchAgents/app.clipdock.ClipDock.plist also remains. To remove everything, delete those folders and files and any saved files you no longer need.
