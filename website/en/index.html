Getting started

The download engine is fetched automatically on first launch.

Read the full guide

  1. Install ClipDock

    On Windows, download the EXE, close ClipDock and run the installer. On Mac, open the DMG and drag ClipDock into Applications.

  2. Open the app

    The first launch downloads the download engine automatically. This requires an internet connection.

  3. Paste a URL and save

    Paste a video URL into 「URLから保存」, choose MP4 or MP3 and a folder, then click 「保存」 (Save).

Frequently asked questions

Which videos can I save?
Supported sites and non-DRM media such as HLS/DASH are handled by the download engine. Site changes and access conditions may prevent a download. Only download media you have the right to save.
Can it save videos that require a login?
“Use login information for this download” is on by default. Sign in to the site you want to save from through the app's Login window first. This is separate from existing Chrome or Edge sessions. A site's restrictions or a post's availability may still prevent a download.
Does choosing 4K improve the source?
The selected resolution is a limit. If the source is only available at 1080p, choosing 4K still gives you up to 1080p. ClipDock does not upscale it.
Why does Windows show a warning?
The current installer has no code signature, so Windows cannot verify its publisher. Check that you downloaded it from this official site. The help page explains how to review the warning.
Why does macOS show a warning?
The current Mac version has no Apple Developer ID signature or notarization, so macOS cannot verify its developer. Check that you downloaded it from this official site. The help page explains how to open it.
