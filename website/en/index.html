Choose the format, quality and folder

Set a quality limit
Choose 480p, 720p, 1080p, 4K or best available for MP4. 4K is a resolution limit; ClipDock does not upscale the source.
Follow each download
See download and conversion progress, cancel a job or retry it. The default is two downloads at a time.
Add a URL
Paste an HTTP(S) video page or media URL. On Windows, an optional tab above Chrome or Edge can also try to import the address.

Getting started

The download engine is fetched automatically on first launch.

Read the full guide

  1. Install ClipDock

    On Windows, download the EXE, quit ClipDock from its notification-area icon and run the installer. On Mac, open the DMG and drag ClipDock into Applications.

  2. Open the app

    The first launch downloads the download engine automatically. This requires an internet connection.

  3. Paste a URL and save

    Paste a video URL into 「URLから保存」, choose MP4 or MP3 and a folder, then click 「保存」 (Save).

Frequently asked questions

What is ClipDock?
ClipDock is a free Windows and Mac app that saves video as MP4 and audio as MP3 from the URL of a video page or media file. It uses yt-dlp and FFmpeg to save, and lets you choose a quality limit, a folder and how many downloads run at once. The app is available in English, Japanese, Simplified Chinese and Spanish.
Which videos can I save?
Supported sites and non-DRM media such as HLS/DASH are handled by the download engine. Site changes and access conditions may prevent a download. Only download media you have the right to save.
Can it save videos that require a login?
“Use login information for this download” is on by default. Sign in to the site you want to save from through the app's Login window first. This is separate from existing Chrome or Edge sessions. A site's restrictions or a post's availability may still prevent a download.
Does choosing 4K improve the source?
The selected resolution is a limit. If the source is only available at 1080p, choosing 4K still gives you up to 1080p. ClipDock does not upscale it.
Why does Windows show a warning?
The current installer has no code signature, so Windows cannot verify its publisher. Check that you downloaded it from this official site. The help page explains how to review the warning.
Why does macOS show a warning?
The current Mac version has no Apple Developer ID signature or notarization, so macOS cannot verify its developer. Check that you downloaded it from this official site. The help page explains how to open it.
Is ClipDock free?
Yes. ClipDock is free, with no ads and no account to create. Download the Windows and Mac versions from this site.
Which computers does it run on?
Windows 10 or 11 (64-bit x64) and Macs with macOS 14 or later (Apple silicon or Intel). You do not need to install .NET or Python separately.
Where are my saved files?
By default in a “ClipDock” folder inside your Downloads folder. Choose another folder with Change folder. When a download finishes, Open and Show file take you straight to it.
Do I need to update it?
No, it updates itself. ClipDock checks for new versions of the app and the download engine when it starts and once a day while it keeps running, and updates when nothing is being saved.
Does it send usage data or personal information?
The app sends no usage data or telemetry. It connects to the video's site to save, and to GitHub and this site to check for updates. See the privacy policy for details.
