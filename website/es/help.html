Instalación

  1. Descarga el instalador (.exe) del sitio oficial.
  2. Cierra ClipDock, abre el instalador y sigue las instrucciones. No requiere permisos de administrador.
  3. Abre ClipDock desde Inicio y pulsa 「保存エンジンを準備」 (Preparar motor). La descarga inicial necesita internet.

Requiere Windows 10 u 11 de 64 bits x64. No es necesario instalar .NET ni Python por separado. Si usas el paquete ZIP, extrae todos los archivos y abre INSTALL.cmd.

Después, 「エンジンの更新を確認」 comprueba las actualizaciones. Una versión idéntica con archivos intactos se reutiliza. Una instalación antigua o archivos dañados pueden requerir descargar de nuevo la misma versión una vez.

La ventana de acceso necesita Microsoft Edge WebView2 Runtime. Si falta, instálalo desde el enlace oficial de Microsoft de esa ventana.

Si Windows muestra una advertencia

El instalador no está firmado, por lo que Windows no puede verificar al editor mediante un certificado. Comprueba que procede de este sitio oficial. Compara su SHA-256 con el valor junto al enlace de descarga para confirmar que coincide con el archivo publicado.

  1. Si has comprobado el origen y decides ejecutarlo, elige «Más información» en SmartScreen.
  2. Selecciona «Ejecutar de todas formas».
  3. Si no aparece esa opción o no puedes verificar el origen, detente y consulta al administrador del equipo. No desactives la protección de Windows.

SHA-256 confirma que los archivos coinciden. No es una firma que identifique al editor.

Guardar desde una URL

  1. Copia la URL de una página o archivo de vídeo y pégala en 「URLから追加」.
  2. Elige el formato. MP4 es el predeterminado; MP3 guarda solo audio.
  3. Elige una carpeta con 「保存先を変更」 y pulsa 「追加」 (Añadir).
  4. Espera a 「保存完了」 (Guardado). Usa 「開く」 para abrir el archivo o 「場所」 para mostrar su carpeta.

El destino predeterminado es ClipDock dentro de Descargas de Windows. Cambiar la carpeta afecta a las tareas añadidas después. Se conservan las opciones de formato, calidad y destino.

Por defecto se procesan dos tareas simultáneas; puedes elegir de una a cuatro. La conversión también cuenta. Reducir el límite no interrumpe las tareas en curso.

Calidad y formatos

MP4 guarda vídeo y MP3 solo audio. El selector de calidad se desactiva al elegir MP3.

480p, 720p, 1080p y 4K son resoluciones máximas. Una fuente de 1080p no se amplía a 4K. «Mejor calidad» tampoco mejora el archivo de origen.

El vídeo y el audio separados comparten un único indicador. La descarga y la conversión llegan al 95 %; se alcanza el 100 % tras verificar el archivo terminado. El MP4 o MP3 final se coloca en la carpeta elegida. MP4 puede conservar el códec original; si tu dispositivo no lo reproduce, prueba 1080p o menos.

Vídeos que requieren iniciar sesión

「この保存にログイン情報を使う」 (Usar los datos de acceso para esta descarga) está activado por defecto y conserva tu elección. Pulsa 「ログイン」 e inicia sesión en el sitio de origen en la ventana propia de ClipDock. Es independiente de Chrome y Edge.

「このページを取り込む」 copia la URL del vídeo al campo de la aplicación. Revísala y pulsa 「追加」.

Al empezar una descarga o reintento se usan las cookies del sitio de destino. Desactivar la opción evita pasarlas a la siguiente tarea añadida o reintentada, pero no cierra la sesión de la ventana.

「ログイン情報を削除」 borra los datos de acceso y navegación de todos los sitios del perfil propio. Termina o cancela primero las tareas activas. Los valores de cookies no se guardan en el historial de descargas y sus archivos temporales se borran al terminar.

El guardado automático de contraseñas está desactivado. Las restricciones del sitio y la disponibilidad del contenido pueden impedir la descarga aunque hayas iniciado sesión.

Pestaña opcional sobre el navegador

「ブラウザー上部に保存タブ」 está desactivada por defecto. Al activarla, puedes intentar importar una URL desde Chrome o Edge.

  1. Pon Chrome o Edge en primer plano y lleva el puntero al centro de la parte superior de la ventana.
  2. Pulsa 「ClipDockに取り込む」 (Importar a ClipDock).
  3. Revisa la URL en la aplicación y pulsa 「追加」. Importar no inicia la descarga.

Si estás editando la dirección o no se puede leer, pégala manualmente. Puede añadirse un https:// omitido en pantalla; comprueba siempre la URL. Esta función no lee cookies, datos de inicio de sesión, contenido de páginas ni historial de navegación.

Tras importar la URL, la descarga utiliza el ajuste de uso de datos de acceso de la aplicación.

Resolver problemas

Error 403, solicitud de acceso o vídeo no encontrado en X
Comprueba la URL y la disponibilidad. Si hace falta, inicia sesión en el sitio de origen en 「ログイン」 y reintenta. No se importan las sesiones del navegador. Las restricciones del sitio pueden seguir impidiendo la descarga.
La tarea sigue en espera
Comprueba que el motor esté preparado. La cola espera mientras se instala el motor.
Falla un sitio compatible
Pulsa 「エンジンの更新を確認」 para buscar actualizaciones. Los cambios o restricciones del sitio pueden impedir la descarga.
Quedan archivos tras cancelar
Los archivos de descarga y conversión se agrupan en la carpeta oculta .clipdock-work/<job-id>/ dentro del destino. Se elimina al terminar correctamente. Al cancelar, fallar o cerrar la aplicación, se conserva para reintentar. Borrar el historial también elimina los archivos de trabajo pendientes de esos registros, pero conserva el contenido terminado.

ClipDock no elimina DRM ni evita restricciones de acceso. No admite directamente URL blob:; usa la URL HTTP(S) de la página del vídeo. Una emisión en directo puede seguir descargándose hasta que termine.

Borrar historial o desinstalar

「履歴を消去」 borra registros completados, fallidos y cancelados junto con sus archivos de trabajo pendientes. No elimina el contenido terminado ni los datos de acceso.

Cierra ClipDock y desinstálalo desde Configuración → Aplicaciones de Windows. Para el paquete ZIP, utiliza UNINSTALL.cmd en la carpeta de instalación.

Los ajustes, el historial y los archivos permanecen. Para borrar todos los datos, cierra la aplicación y elimina %LOCALAPPDATA%\ClipDock y los archivos guardados que no necesites.

El perfil de acceso también permanece tras desinstalar. Para borrar solo los datos de acceso, usa 「ログイン情報を削除」 en la ventana correspondiente.
