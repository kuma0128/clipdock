Elige formato, calidad y carpeta

Limita la resolución
Para MP4, elige 480p, 720p, 1080p, 4K o la mejor calidad disponible. 4K es un límite; ClipDock no amplía la resolución del original.
Consulta el progreso
Comprueba la descarga y la conversión, cancela una tarea o vuelve a intentarlo. Por defecto se procesan dos a la vez.
Añade una URL
Pega una URL HTTP(S) de una página o archivo de vídeo. En Windows, una pestaña opcional sobre Chrome o Edge también permite intentar importar la dirección.

Primeros pasos

El motor de descarga se obtiene automáticamente en el primer inicio.

Leer la guía completa

  1. Instala ClipDock

    En Windows, descarga el EXE, sal de ClipDock desde su icono del área de notificación y ejecuta el instalador. En Mac, abre el DMG y arrastra ClipDock a Aplicaciones.

  2. Abre la aplicación

    En el primer inicio se descarga el motor automáticamente. Requiere conexión a internet.

  3. Pega una URL y guarda

    Pega la URL en «Guardar desde una URL», elige MP4 o MP3 y una carpeta, y pulsa «Guardar».

Preguntas frecuentes

¿Qué es ClipDock?
ClipDock es una aplicación gratuita para Windows y Mac que guarda vídeo en MP4 y audio en MP3 a partir de la URL de una página de vídeo o de un archivo multimedia. Usa yt-dlp y FFmpeg para guardar, y permite elegir el límite de calidad, la carpeta y cuántas descargas se hacen a la vez. Está disponible en español, inglés, japonés y chino simplificado.
¿Qué vídeos puedo guardar?
El motor permite descargar desde sitios compatibles y medios sin DRM, como HLS/DASH. Los cambios del sitio o sus condiciones de acceso pueden impedirlo. Descarga únicamente contenido que tengas derecho a guardar.
¿Funciona con vídeos que requieren iniciar sesión?
«Usar sesión para esta descarga» está activado por defecto. Primero pulsa «Acceder» en la aplicación e inicia sesión en el sitio de origen, en una ventana separada de Chrome y Edge. Las restricciones del sitio o la disponibilidad del contenido pueden impedir la descarga incluso con sesión iniciada.
¿Elegir 4K mejora la calidad?
La resolución seleccionada es un límite. Si la fuente solo ofrece 1080p, elegir 4K sigue dando como máximo 1080p. ClipDock no amplía la resolución.
¿Por qué Windows muestra una advertencia?
El instalador actual no tiene firma de código y Windows no puede verificar su editor. Comprueba que lo has descargado de este sitio oficial. La ayuda explica cómo revisar la advertencia.
¿Por qué macOS muestra una advertencia?
La versión actual para Mac no tiene firma de Apple Developer ID ni certificación de Apple, por lo que macOS no puede verificar al desarrollador. Comprueba que la has descargado de este sitio oficial. La ayuda explica cómo abrirla.
¿Es seguro usar ClipDock?
ClipDock no tiene anuncios ni telemetría y no envía datos de uso. Los instaladores aún no tienen firma de código, así que descárgalos solo desde este sitio y comprueba que coinciden con los valores SHA-256 de la sección de descarga. Las actualizaciones automáticas también se usan solo si su tamaño y su SHA-256 coinciden con la información de actualización de este sitio. Los inicios de sesión se guardan en la ventana de acceso propia de ClipDock; no lee las cookies ni las contraseñas del navegador que usas normalmente.
¿Cuál es el sitio oficial de ClipDock?
Este sitio, clipdock-d6z.pages.dev, es el sitio oficial de ClipDock para Windows y Mac. Otras aplicaciones y servicios web que también se llaman ClipDock no tienen relación con él. Descarga los instaladores solo desde este sitio.
¿ClipDock es gratis?
Sí. ClipDock es gratuito, sin anuncios ni registro de cuenta. Descarga las versiones para Windows y Mac desde este sitio.
¿En qué ordenadores funciona?
En Windows 10 u 11 (64 bits x64) y en Mac con macOS 14 o posterior (Apple silicon o Intel). No hay versión para iPhone, Android ni Linux. No hace falta instalar .NET ni Python por separado.
¿Dónde se guardan los archivos?
De forma predeterminada, en una carpeta «ClipDock» dentro de Descargas. Puedes elegir otra con Cambiar carpeta. Al terminar una descarga, Abrir y Ubicación te llevan directamente al archivo.
¿Tengo que actualizarlo?
No, se actualiza solo. ClipDock busca versiones nuevas de la aplicación y del motor al iniciarse y una vez al día mientras sigue abierto, y se actualiza cuando no se está guardando nada.
¿Envía datos de uso o información personal?
La aplicación no envía datos de uso ni telemetría. Se conecta al sitio del vídeo para guardarlo, y a GitHub y a este sitio para buscar actualizaciones. Consulta la política de privacidad para más detalles.
