Privacidad

Actualizado: 23 de noviembre de 2026

Esta política cubre ClipDock para Windows y su sitio oficial. ClipDock guarda vídeo y audio en tu PC a partir de las URL que proporcionas. La aplicación no incorpora informes de uso, publicidad, analítica ni telemetría. El sitio web cuenta las visitas con Cloudflare Web Analytics, que no usa cookies.

Las instrucciones de acceso, pestaña del navegador y almacenamiento siguientes corresponden a Windows. Consulta Diferencias en Mac para la versión de Mac.

Datos de acceso en la aplicación

«Usar los datos de acceso para esta descarga» está activado por defecto y se conserva localmente. Desactivarlo evita pasar cookies de acceso al motor en la siguiente tarea añadida o reintentada. La ventana propia sigue con la sesión iniciada.

Utiliza Acceder para iniciar sesión en el sitio de origen en una ventana WebView2 con perfil independiente de Chrome y Edge. Los datos introducidos se envían al sitio correspondiente. El guardado automático de contraseñas y el autocompletado general están desactivados.

También se consultan las cookies del perfil propio para mostrar el estado de la sesión. Cuando la opción está activada, cada descarga o reintento exporta solo las cookies del sitio de destino a un archivo temporal del motor. Sus valores no se incluyen en el historial de descargas y se eliminan de los mensajes de error del motor.

«Borrar datos de acceso» elimina los datos de acceso y navegación de todos los sitios en ClipDock. No puede utilizarse con tareas activas: termínalas o cancélalas primero. Las páginas abiertas en la aplicación también están sujetas a sus propias condiciones y políticas de privacidad.

Pestaña opcional del navegador

Está desactivada por defecto. Al activarla, la aplicación comprueba el tipo y la posición de la ventana de Chrome o Edge en primer plano y la posición del puntero. No guarda un historial de movimientos. Desactivarla detiene estas comprobaciones.

La barra de direcciones solo se lee al pulsar la pestaña. Windows UI Automation obtiene una URL candidata y la muestra en la aplicación. La descarga no empieza hasta que compruebas la URL y pulsas Guardar.

No lee contenido de páginas, cookies, historial ni portapapeles. No recoge URL de forma continua. También puedes pegar la dirección manualmente.

El idioma elegido también se guarda en el archivo de ajustes.

Las cookies temporales se borran al completar, fallar o cancelar. Si el borrado falla o hay un cierre inesperado, se intenta de nuevo al iniciar.

Borrar el historial elimina los archivos de trabajo pendientes asociados, pero no el contenido terminado ni los datos de acceso. La desinstalación conserva ajustes, historial, perfil de acceso y archivos. Para borrar todos los datos, cierra la aplicación y elimina %LOCALAPPDATA%\ClipDock, el contenido que no necesites y las carpetas .clipdock-work restantes en los destinos.

Diferencias en Mac

La versión para Mac trata la misma información con los mismos fines y se conecta a los mismos servicios que la versión para Windows. La ubicación y la protección de los datos difieren en lo siguiente.

  • Los ajustes, el historial y el motor de descarga se guardan en ~/Library/Application Support/ClipDock. El historial no se cifra; el acceso a la carpeta y a los archivos se limita al usuario actual.
  • La ventana de acceso usa el motor WebKit integrado en macOS. Las cookies y los datos de navegación se conservan en datos de WebKit propios de la aplicación (por ejemplo, ~/Library/WebKit/app.clipdock.ClipDock) y no se comparten con Safari ni con otros navegadores.
  • «Eliminar los datos de acceso» borra las cookies de todos los sitios en ClipDock.
  • No hay pestaña opcional sobre el navegador. La versión para Mac no lee las ventanas ni las barras de direcciones de otras aplicaciones.
  • Al mover la aplicación a la Papelera, los ajustes, el historial, los datos de acceso y los archivos guardados permanecen.

Conexiones y uso de la información

Las descargas envían URL, referencia, User-Agent del motor y otros datos necesarios a proveedores y sitios requeridos para analizar la página. Si se usa la sesión, las cookies también autentican solicitudes al sitio correspondiente. Estos sitios reciben tu IP.

La aplicación prepara y actualiza el motor automáticamente al iniciarse, obteniendo archivos y licencias desde GitHub. La ventana de acceso conecta con los sitios HTTPS que abres y las páginas necesarias para autenticarte. Utiliza Microsoft Edge WebView2 Runtime en Windows y WebKit en Mac.

No se venden datos ni se usan para publicidad, evaluación crediticia o análisis ajenos al guardado de contenido. El desarrollador no puede obtener tu historial de descargas ni tus cookies mediante la aplicación.

Sitio web y descargas

El sitio oficial, las guías, la ayuda y el instalador se distribuyen mediante Cloudflare. Este procesa datos de conexión como IP, URL solicitada e información del navegador para la entrega y la seguridad. Consulta la política de privacidad de Cloudflare.

El sitio usa Cloudflare Web Analytics para conocer cómo se utiliza. Cuenta las URL de las páginas, la procedencia, el país o la región, el tipo de navegador y dispositivo y el tiempo de carga. No usa cookies ni identificadores guardados en tu dispositivo, y los resultados no se usan para identificar a visitantes concretos. El sitio no contiene publicidad ni scripts de seguimiento. La aplicación no envía al sitio el historial de descargas ni datos de acceso.

Ayuda y cambios

Esta política se actualizará si cambia el tratamiento de la información.
