インストールから保存までの手順と、うまくいかないときの確認方法です。

インストール

Windows

  1. 公式サイトからインストーラー（.exe）を取得します。
  2. 起動中のClipDockを終了し（通知領域のアイコンを右クリックして「ClipDockを終了」）、インストーラーを開いて画面の案内に従います。管理者権限は不要です。
  3. スタートメニューから起動します。初回の起動時に保存エンジンを自動で取得するため、インターネット接続が必要です。

Windows 10 / 11の64bit版に対応します。.NETやPythonの別途インストールは不要です。ZIP版を使う場合だけ、すべて展開してINSTALL.cmdを開いてください。

保存エンジンの更新は、アプリの起動時と、起動したままの間は1日に1回、自動で確認します。同じ版でファイルが正常なら再取得しません。旧版からの更新直後やファイルが壊れている場合は、一度取得し直すことがあります。取得に失敗したときは「保存エンジンを準備」が表示され、押すと取得し直します。

ログイン画面にはMicrosoft Edge WebView2 Runtimeが必要です。見つからない場合はログイン画面のMicrosoft公式案内から導入してください。

Mac

  1. 公式サイトから、お使いのMacに合うディスクイメージ（.dmg）を取得します。Appleシリコンはarm64、Intelはx64です。
  2. ディスクイメージを開き、ClipDockを「アプリケーション」フォルダーへドラッグします。
  3. 「アプリケーション」から起動します。初回起動時に保存エンジンを取得するため、インターネット接続が必要です。

macOS 14以降に対応します。ログイン画面はmacOS標準のWebKitを使うため、追加のソフトウェアは不要です。「ブラウザー上部の保存タブ」はMac版にはありません。

常駐と自動起動

ClipDockは初期設定で、Windowsへのサインイン時（Macはログイン時）に自動で起動し、Windowsは通知領域、Macはメニューバーで待機します。ウィンドウの閉じるボタンを押しても終了せず、保存中の動画はそのまま続きます。

  • 通知領域のアイコンをクリックする（Macはメニューバーのアイコンから「ClipDockを開く」を選ぶ）か、スタートメニューや「アプリケーション」からClipDockを起動すると、ウィンドウが開きます。
  • 終了するには、アイコンを右クリック（Macはアイコンのメニュー）して「ClipDockを終了」を選びます。保存中は中断確認が出ます。
  • 自動起動は左下の「Windowsの起動時に開始」（Macは「ログイン時に開く」）で切り替えます。Windowsの「設定」→「アプリ」→「スタートアップ」やMacの「ログイン項目」でOFFにした場合は、そちらが優先されます。
  • Windowsでは、アイコンは初め、タスクバーの「^」で開く一覧に入ります。常に表示する場合は、タスクバーの設定でClipDockをONにします。

アプリの自動アップデート

ClipDockは、起動時と、起動したままの間は1日に1回、新しいバージョンを確認します。見つかるとバックグラウンドでダウンロードし、このサイトの更新情報とサイズ・SHA-256が一致することを確かめてから使います。

  • 保存中・待機中の動画がなく、ウィンドウを閉じて通知領域・メニューバーにあるときに、自動で更新してClipDockを起動し直します。
  • ウィンドウを開いている間は、左下に「再起動して ClipDock ○○ に更新」が表示されます。押すとすぐに更新します。
  • 更新後は、更新したことを一度だけ表示します。設定・履歴・保存ファイルはそのまま残ります。
  • 自動アップデートに対応していない以前のバージョンを使っている場合は、一度だけこのサイトから新しいバージョンを入れてください。ZIPを展開したまま使う場合や、Macでディスクイメージから直接開いた場合は自動アップデートしません。

Windowsに警告が表示されたら

配布インストーラーは未署名で、Windowsが発行元を証明書で確認できません。この公式サイトから取得したことを確認してください。ダウンロード欄のSHA-256と比較すると、ファイルが配布物と同じか確認できます。

  1. 取得元を確認して実行する場合は、SmartScreenの「詳細情報」を選びます。
  2. 「実行」を選びます。
  3. 「実行」がない場合や取得元を確認できない場合は中止し、端末の管理者に確認してください。保護機能を無効にする必要はありません。

SHA-256はファイルの一致を確認する値です。発行元を証明する署名ではありません。

Macに警告が表示されたら

Mac版にはApple Developer IDの署名と公証がなく、macOSが開発元を確認できません。この公式サイトから取得したことを確認してください。ダウンロード欄のSHA-256と比較すると、ファイルが配布物と同じか確認できます。

  1. 警告が表示されたら、いったん閉じます。
  2. 取得元を確認して開く場合は、「システム設定」→「プライバシーとセキュリティ」を開き、ClipDockの「このまま開く」を選びます。
  3. この項目が表示されない場合や取得元を確認できない場合は中止してください。Gatekeeperを無効にする必要はありません。

表示言語

初めて起動したときは、パソコンの表示言語が日本語・英語・簡体字中国語・スペイン語ならその言語、それ以外なら英語で表示します。Macでは、「システム設定」→「一般」→「言語と地域」の優先する言語を上から順に見て、最初に対応している言語を使います。左下の「言語（次回起動から適用）」で日本語・English・简体中文・Españolに変更できます。選択は保存され、アプリを閉じて開き直すと反映します。進行中の保存は、言語の変更だけでは中断しません。以下は日本語表示での操作名です。

URLから保存する

  1. 動画ページまたは動画ファイルのURLをコピーし、「URLから保存」に貼り付けます。
  2. 形式を選びます。初期値はMP4で、MP3は音声のみを保存します。
  3. 「保存先を変更」でフォルダーを選び、「保存」を押します。
  4. 「保存完了」になったら、「開く」で再生、「場所」でフォルダーを開けます。

初期保存先はWindows・Macともダウンロードフォルダー内のClipDockです。保存先の変更は、その後に保存する項目に適用します。形式・画質・保存先は次回も保持します。

同時保存は初期2件で、1〜4件に変更できます。変換中も件数に含みます。数を減らしても進行中の保存は中断しません。

画質と保存形式

MP4は動画、MP3は音声のみを保存します。MP3を選ぶと画質欄は無効になります。

480p・720p・1080p・4Kは解像度の上限です。1080pまでの配信を4Kに拡大することはありません。最高画質でも、元の配信より高画質にはなりません。

映像と音声を別々に取得する場合も、全体を1件の進捗で表示します。取得・変換は95%まで進み、完成ファイルの確認が終わると100%になります。完成したMP4・MP3を保存先に配置します。MP4は元の映像コーデックを保持する場合があるため、再生できない機器では1080p以下を試してください。

ログインが必要な動画

「この保存にログイン情報を使う」は初期ONで、変更した設定も保持します。初回は「ログイン」を押し、ClipDock専用画面で保存対象のサイトへサインインします。Chrome・Edgeのログインとは別です。

専用画面の「このページを取り込む」で動画のURLを入力欄へ渡せます。URLを確認して「保存」を押してください。

保存開始・再試行時に対象サイトのCookieを使います。OFFでは次の保存・再試行にCookieを渡しません。OFFにしてもサインイン状態は残ります。

「ログイン情報を削除」で専用画面の全サイトのログイン情報と閲覧データを消せます。保存の完了またはキャンセル後に実行してください。Cookieを保存履歴に残さず、一時ファイルは処理終了時に削除します。

パスワードの自動保存は無効です。サイト側の制限や投稿の公開条件により、サインインしても保存できない場合があります。

ブラウザー上部の保存タブ

Windows版の機能です。Mac版にはありません。

「ブラウザー上部に保存タブ」は初期OFFです。ONにすると、Chrome・EdgeのURLを取り込める場合があります。

  1. ChromeまたはEdgeを前面に出し、ウィンドウ上部の中央にマウスを合わせます。
  2. 「ClipDockに取り込む」を押します。
  3. アプリに入ったURLを確認し、「保存」を押します。取り込みだけでは保存を開始しません。

アドレスを編集中の場合や読み取れない場合は手動で貼り付けてください。表示で省略されたhttps://が補われることもあるため、必ずURLを確認してください。Cookie、ログイン情報、ページ本文、閲覧履歴は読み取りません。

URLを取り込んだ後の保存には、アプリの「この保存にログイン情報を使う」の設定が適用されます。

保存できないとき

403・ログイン要求・Xで動画が見つからない
公開状態とURLを確認し、必要ならアプリ内の「ログイン」で保存対象のサイトにサインインしてから再試行してください。既存ブラウザーのログイン状態は引き継ぎません。サイト側の制限によっては保存できない場合があります。
待機したまま動かない
保存エンジンの取得中はキューが待機します。「保存エンジンを準備」が表示されている場合は、通信環境を確認して押してください。
対応サイトなのに失敗する
ClipDockは起動時と1日に1回、保存エンジンの更新を確認します。すぐに確認するには、ClipDockを終了してから起動し直してください。サイトの変更や制限で取得できない場合もあります。
キャンセル後にファイルが残る
取得・変換中のファイルは保存先の隠しフォルダー.clipdock-work/<job-id>/にまとめます。完了時に作業フォルダーを削除します。キャンセル・失敗・アプリ終了時は再試行用に残し、「履歴を消去」で対象項目の作業ファイルも削除します。完成ファイルは消しません。

DRMやアクセス制限の解除は行いません。blob: URLそのものは使えないため、動画があるページのHTTP(S) URLを指定してください。ライブ配信は終了まで長時間動作することがあります。

履歴の削除・アンインストール

「履歴を消去」は完了・失敗・キャンセルした履歴と、対象項目に残る未完了の作業ファイルを削除します。完成した動画・音声とログイン情報は削除しません。

通知領域のアイコンから「ClipDockを終了」で終了し、Windowsの「設定」→「アプリ」からアンインストールします。ZIP版はインストール先のUNINSTALL.cmdを使います。どちらも自動起動の登録を削除します。

設定・履歴・保存ファイルは残ります。すべて削除するには、ClipDockを終了して%LOCALAPPDATA%\ClipDockと不要な保存ファイルを削除してください。

ログイン用プロファイルもアンインストール後に残ります。ログイン情報だけを消す場合は、専用ログイン画面の「ログイン情報を削除」を使います。

Mac版は、メニューバーのアイコンから「ClipDockを終了」で終了し、「アプリケーション」フォルダーのClipDockをゴミ箱へ移します。設定・履歴・ログイン用のデータは~/Library/Application Support/ClipDockと~/Library/WebKit/app.clipdock.ClipDockに残ります。ログイン時の自動起動の設定ファイル~/Library/LaunchAgents/app.clipdock.ClipDock.plistも残ります。すべて削除するには、これらのフォルダー・ファイルと不要な保存ファイルを削除してください。
