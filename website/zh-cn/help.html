安装

Windows

  1. 从官方网站下载安装程序（.exe）。
  2. 退出 ClipDock（右键点击通知区域图标并选择“退出 ClipDock”），然后打开安装程序并按提示操作。无需管理员权限。
  3. 从开始菜单打开应用。首次启动时会自动下载引擎，需要联网。

需要 Windows 10 或 11 的 x64 64 位版本，无需单独安装 .NET 或 Python。使用 ZIP 包时，请完整解压并运行 INSTALL.cmd。

应用会在启动时以及保持运行期间每天自动检查一次引擎更新。版本未变且文件正常时不会重复下载。旧版本升级后或文件损坏时，可能需要重新下载一次相同版本。下载失败时会显示“准备下载引擎”，点击即可重试。

登录窗口需要 Microsoft Edge WebView2 Runtime。如果未安装，请使用该窗口中的 Microsoft 官方链接安装。

Mac

  1. 从本官方网站下载与您的 Mac 相符的磁盘映像（.dmg）：Apple 芯片选择 arm64，Intel 选择 x64。
  2. 打开磁盘映像，将 ClipDock 拖到“应用程序”文件夹。
  3. 从“应用程序”中打开。首次启动时会下载引擎，需要联网。

支持 macOS 14 及以上版本。登录窗口使用 macOS 自带的 WebKit，无需另外安装软件。Mac 版不提供浏览器上方的可选标签。

后台运行与自动启动

默认情况下，ClipDock 会在登录 Windows（或 Mac）时自动启动，并在 Windows 的通知区域或 Mac 的菜单栏中待命。关闭窗口不会退出应用，正在进行的下载会继续。

  • 点击通知区域图标（Mac 上从菜单栏图标选择“打开 ClipDock”），或从开始菜单、“应用程序”打开 ClipDock，即可显示窗口。
  • 要退出，请右键点击图标（Mac 上使用图标菜单）并选择“退出 ClipDock”。有正在下载的任务时会先询问。
  • 可通过左下角的“随 Windows 启动”（Mac 为“登录时打开”）开启或关闭自动启动。如果在 Windows“设置”→“应用”→“启动”或 Mac 的“登录项”中关闭，则以系统设置为准。
  • 在 Windows 上，图标起初位于任务栏“^”按钮后的列表中。若要始终显示，请在任务栏设置中开启 ClipDock。

应用自动更新

ClipDock 会在启动时以及保持运行期间每天检查一次新版本。发现新版本后会在后台下载，并在大小和 SHA-256 与本网站的更新信息一致时才使用。

  • 没有正在保存或等待的任务，且窗口已关闭到通知区域或菜单栏时，ClipDock 会自动更新并重新启动。
  • 窗口打开时，左下角会显示“重启并更新到 ClipDock …”。点击即可立即更新。
  • 更新后会提示一次。设置、历史记录和已保存的文件都会保留。
  • 如果您使用的是不支持自动更新的旧版本，请从本网站手动安装一次新版本。直接从解压的 ZIP 运行，或在 Mac 上直接从磁盘映像打开时，不会自动更新。

Windows 显示警告时

安装程序未签名，Windows 无法通过证书验证发布者。请确认文件来自本官方网站。将文件的 SHA-256 与下载链接旁提供的值进行比较，可以确认文件是否与发布文件一致。

  1. 确认来源并决定运行后，在 SmartScreen 中选择“更多信息”。
  2. 选择“仍要运行”。
  3. 如果没有该选项，或无法确认来源，请停止并联系设备管理员。请勿关闭 Windows 安全保护。

SHA-256 用于确认文件一致性，并不是证明发布者身份的签名。

macOS 显示警告时

Mac 版没有 Apple Developer ID 签名，也未经公证，macOS 无法验证开发者。请确认文件来自本官方网站。与下载处的 SHA-256 比较，可确认文件与发布的文件一致。

  1. 出现警告时，先将其关闭。
  2. 确认来源并决定打开时，前往“系统设置”→“隐私与安全性”，为 ClipDock 选择“仍要打开”。
  3. 如果没有该选项，或无法确认来源，请停止操作。无需关闭 Gatekeeper。

显示语言

首次启动时，如果电脑的显示语言是日语、英语、简体中文或西班牙语，ClipDock 会使用该语言；其他语言（包括繁体中文）显示为英语。在 Mac 上，ClipDock 会按“系统设置”→“通用”→“语言与地区”中首选语言的顺序，使用第一个受支持的语言。如需更改，请在左下角的“语言（重启后生效）”中选择日本語、English、简体中文或 Español。设置会保存，关闭并重新打开应用后生效。仅更改语言不会中断下载。

通过网址保存

  1. 复制视频页面或媒体文件的网址，粘贴到“从网址保存”。
  2. 选择格式。默认为 MP4；MP3 仅保存音频。
  3. 通过“更改位置”选择文件夹，然后点击“保存”。
  4. 等待显示“已保存”。点击“打开”打开文件，或点击“位置”打开所在文件夹。

默认位置为 Windows 和 Mac 下载文件夹中的 ClipDock。更改保存位置仅影响之后添加的任务。格式、画质和保存位置会保留到下次使用。

默认同时处理两个任务，可调整为一至四个。转换也计入并行任务数。调低上限不会中断已经运行的任务。

画质与文件格式

MP4 保存视频，MP3 仅保存音频。选择 MP3 时，画质选项会被禁用。

480p、720p、1080p 和 4K 是分辨率上限。不会将 1080p 源视频放大为 4K。“最佳画质”也不能超出源视频本身的画质。

即使分别下载音视频，也只使用一个总进度。下载和转换阶段最多推进到 95%，完成文件验证后才达到 100%，并将 MP4 或 MP3 放入保存文件夹。MP4 可能保留源视频编码；设备无法播放时，可以尝试 1080p 或更低分辨率。

需要登录的视频

“使用登录信息保存”默认开启，并保留您的选择。点击“登录”，在 ClipDock 专用窗口中登录您要保存内容的网站，与 Chrome、Edge 的会话分开。

点击“导入此页面”可将视频网址填入主窗口，确认后再点击“保存”。

开始保存或重试时，应用使用目标网站的 Cookie。关闭选项后，下一次添加或重试不会向引擎传递 Cookie，但登录窗口仍保持登录。

“删除登录信息”会清除专用配置文件中所有网站的登录信息与浏览数据。请先完成或取消活动任务。Cookie 值不写入下载历史；处理完成后会删除临时 Cookie 文件。

密码自动保存已禁用。即使已登录，网站限制和内容公开条件仍可能导致下载失败。

浏览器上方的可选标签

此功能仅适用于 Windows 版，Mac 版不提供。

“显示浏览器顶部保存标签”默认关闭。开启后，可尝试从 Chrome 或 Edge 导入网址。

  1. 将 Chrome 或 Edge 置于前台，将鼠标移到窗口顶部中央。
  2. 点击“导入 ClipDock”。
  3. 检查应用中填入的网址，然后点击“保存”。仅导入不会开始下载。

正在编辑地址或无法读取时，请手动粘贴。浏览器省略的 https:// 可能会被补全，因此必须确认网址。该功能不读取 Cookie、登录信息、页面内容或浏览历史。

导入网址后，保存时会应用主窗口中的登录信息使用设置。

无法保存时

403、要求登录，或在 X 上找不到视频
检查网址和公开状态。如有需要，先点击应用中的“登录”，登录您要保存内容的网站，再重试。不会导入现有浏览器会话。网站限制仍可能导致无法保存。
任务一直等待
引擎安装期间，任务队列会等待。如果显示“准备下载引擎”，请检查网络后点击。
支持的网站仍下载失败
ClipDock 会在启动时和每天检查一次引擎更新。若要立即检查，请退出 ClipDock 后重新打开。网站变化或限制仍可能导致失败。
取消后仍有文件
下载和转换文件集中存放在保存位置的隐藏文件夹 .clipdock-work/<job-id>/。成功后删除该工作文件夹；取消、失败或退出应用时保留，以便重试。清除历史记录也会删除对应任务未完成的工作文件，但保留已完成的媒体。

ClipDock 不解除 DRM 或访问限制。不能直接使用 blob: 网址，请使用视频所在页面的 HTTP(S) 网址。直播任务可能持续到直播结束。

删除历史记录或卸载

“清除历史”会清除已完成、失败和取消的记录，以及对应任务未完成的工作文件，不删除已完成的媒体或登录信息。

从通知区域图标选择“退出 ClipDock”退出后，在 Windows“设置”→“应用”中卸载。ZIP 版使用安装文件夹内的 UNINSTALL.cmd。两种方式都会删除自动启动的登记。

设置、历史记录和保存文件会保留。若要全部删除，请退出 ClipDock，删除 %LOCALAPPDATA%\ClipDock 和不需要的保存文件。

卸载后也会保留专用登录配置文件。若只想清除登录信息，可使用登录窗口中的“删除登录信息”。

Mac 版：从菜单栏图标选择“退出 ClipDock”后，将“应用程序”文件夹中的 ClipDock 移到废纸篓。设置、历史记录和登录数据会保留在 ~/Library/Application Support/ClipDock 和 ~/Library/WebKit/app.clipdock.ClipDock 中。登录时自动启动的设置文件 ~/Library/LaunchAgents/app.clipdock.ClipDock.plist 也会保留。如需全部删除，请删除这些文件夹和文件以及不再需要的已保存文件。
