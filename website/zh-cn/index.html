指定格式、画质和保存位置

设置画质上限
MP4 可选择 480p、720p、1080p、4K 或最佳可用画质。4K 是分辨率上限，不会将原视频放大。
查看保存进度
正在保存的任务显示在“已保存的文件”列表顶部，可查看下载和转换进度，按需取消或重试。每次同时保存两个任务，其余任务自动排队。
通过网址添加
输入视频页面或媒体文件的 HTTP(S) 网址，Windows 版还可尝试使用 Chrome、Edge 上方的可选标签导入地址。

开始使用

首次启动时会自动下载引擎。

查看完整使用说明

  1. 安装应用

    Windows 用户请下载 EXE，从通知区域图标退出 ClipDock 后运行安装程序。Mac 用户请打开 DMG，将 ClipDock 拖入“应用程序”。

  2. 打开应用

    首次启动时会自动下载引擎，需要联网。

  3. 粘贴网址并保存

    在“从网址保存”中粘贴视频网址，选择 MP4 或 MP3 及保存位置，然后点击“保存”。

常见问题

ClipDock 是什么？
ClipDock 是一款免费的 Windows 和 Mac 应用，粘贴视频页面或媒体文件的网址，即可将视频保存为 MP4、音频保存为 MP3。它使用 yt-dlp 和 FFmpeg 进行保存，可以选择画质上限和保存位置，并在“已保存的文件”列表中查看保存进度和结果。界面支持简体中文、英语、日语和西班牙语。
可以保存哪些视频？
支持下载引擎可处理的网站视频以及未受 DRM 保护的 HLS、DASH 等媒体。网站变化或访问条件可能导致无法保存。请仅下载您有权保存的内容。
可以保存需要登录的视频吗？
“使用登录信息保存”默认开启。首次使用时，请点击应用中的“登录”，登录您要保存内容的网站，与 Chrome、Edge 的现有会话分开。即使已登录，网站限制或帖子的公开状态仍可能导致无法保存。
选择 4K 会提升画质吗？
所选分辨率是上限。如果源视频最高为 1080p，选择 4K 后仍最多保存为 1080p，不会进行放大处理。
为什么 Windows 会显示警告？
当前安装程序未进行代码签名，Windows 无法验证发布者。请确认文件来自本官方网站。帮助页提供了详细的确认方法。
为什么 macOS 会显示警告？
当前 Mac 版没有 Apple Developer ID 签名，也未经公证，macOS 无法验证开发者。请确认文件来自本官方网站。帮助页说明了打开方法。
ClipDock 安全吗？
ClipDock 没有广告和遥测，不会发送使用情况数据。安装程序目前没有代码签名，请只从本网站下载，并确认文件与下载区显示的 SHA-256 一致。自动更新也只会使用大小和 SHA-256 与本网站更新信息一致的文件。登录信息保存在 ClipDock 专用的登录窗口中，不会读取您平时使用的浏览器的 Cookie 或密码。
ClipDock 的官方网站在哪里？
本网站 clipdock-d6z.pages.dev 是 Windows 和 Mac 版 ClipDock 的官方网站。其他同样名为 ClipDock 的应用或网络服务与本应用无关。请只从本网站下载安装程序。
ClipDock 免费吗？
是的。ClipDock 免费使用，没有广告，也无需注册账号。Windows 版和 Mac 版都可以从本网站下载。
支持哪些电脑？
支持 Windows 10 或 11（64 位 x64），以及 macOS 14 及以上版本的 Mac（Apple 芯片或 Intel）。没有 iPhone、Android 或 Linux 版本。无需另外安装 .NET 或 Python。
保存的文件在哪里？
默认保存在“下载”文件夹中的“ClipDock”文件夹。可以通过“更改位置”选择其他文件夹。保存完成后，可在“已保存的文件”列表中点击“打开”或“位置”查看文件，或点击“打开文件夹”打开保存位置。
需要手动更新吗？
不需要，ClipDock 会自动更新。它会在启动时以及保持运行期间每天检查一次应用和下载引擎的新版本，并在没有正在保存的任务时更新。
会发送使用情况或个人信息吗？
应用不会发送使用情况或遥测数据。保存时会连接视频所在的网站，检查更新时会连接 GitHub 和本网站。详情请参阅隐私政策。
