隐私政策

更新日期：2026年11月23日

本政策适用于 ClipDock Windows 应用及其官方网站。ClipDock 根据您提供的网址，将视频和音频保存到电脑。应用本身不提供使用情况报告、广告、访问分析或遥测。官方网站使用不依赖 Cookie 的 Cloudflare Web Analytics 统计访问情况。

下方关于登录窗口、浏览器标签和存储位置的说明适用于 Windows 版。Mac 版请参阅“Mac 版的区别”。

应用内的登录信息

“在此次保存中使用登录信息”默认开启，设置保存在本机。关闭后，下一次添加或重试不会向引擎传递登录 Cookie，但专用窗口仍保持登录。

通过登录按钮，在专用 WebView2 窗口中登录您要保存内容的网站。该配置文件与 Chrome、Edge 分开。登录页面输入的信息会发送到相应网站。密码自动保存和通用自动填充已禁用。

应用也会检查专用配置文件的 Cookie，以显示登录状态。开启使用选项时，每次保存或重试仅将目标网站的 Cookie 导出到引擎临时文件。Cookie 值不会写入下载历史，并会从引擎错误显示中移除。

“删除登录信息”会清除 ClipDock 内所有网站的登录信息和浏览数据。活动任务期间不可操作，请先完成或取消任务。应用内打开的网页也适用相应网站的条款和隐私政策。

可选浏览器标签

该选项默认关闭。开启后，应用检查前台 Chrome 或 Edge 窗口的类型与位置，以及鼠标位置，不保存鼠标移动历史。关闭选项会停止这些检查。

只有点击标签时才读取地址栏，通过 Windows UI Automation 获取网址候选值并显示在应用内。确认网址并点击保存之前，不会开始保存。

该功能不读取页面内容、Cookie、浏览历史或剪贴板，也不会持续收集网址。您可以直接手动粘贴网址。

显示语言也会保存在设置文件中。

Mac 版的不同之处

Mac 版处理的信息、目的和连接的服务与 Windows 版相同。保存位置和保护方式有以下不同。

  • 设置、历史记录和下载引擎保存在 ~/Library/Application Support/ClipDock。历史记录不加密；文件夹和文件的访问权限仅限当前用户。
  • 登录窗口使用 macOS 自带的 WebKit。Cookie 和浏览数据保存在应用专用的 WebKit 数据中（例如 ~/Library/WebKit/app.clipdock.ClipDock），不与 Safari 或其他浏览器共享。
  • “删除登录信息”会删除 ClipDock 中所有网站的 Cookie。
  • 不提供浏览器上方的可选标签。Mac 版不会读取其他应用的窗口或地址栏。
  • 将应用移到废纸篓后，设置、历史记录、登录数据和已保存的文件仍会保留。

网络连接与信息使用

保存媒体时，会向媒体提供方及解析所需的网站发送网址、来源地址、引擎 User-Agent 等必要信息。开启登录信息使用时，也会通过对应网站的 Cookie 进行认证。这些网站会收到您的 IP 地址。

应用启动时会自动准备或更新引擎，并从 GitHub 获取发行文件和许可证。专用登录窗口连接您打开的 HTTPS 网站及所需的认证页面，在 Windows 上使用 Microsoft Edge WebView2 Runtime，在 Mac 上使用 WebKit。

用户数据不会出售，也不用于广告、信用评估或与媒体保存无关的分析。开发者没有获取下载历史或 Cookie 的机制。

官方网站与下载

官方网站、操作指南、帮助和安装程序通过 Cloudflare 提供。Cloudflare 为内容分发和安全处理 IP 地址、访问网址、浏览器信息等连接数据。具体处理方式见 Cloudflare 隐私政策。

本网站使用 Cloudflare Web Analytics 了解访问情况，统计页面网址、来源、国家或地区、浏览器和设备类型以及页面加载速度等。不使用 Cookie 或保存在设备上的标识符，统计结果不用于识别个人访问者。本网站未添加广告或跟踪脚本。应用不会向网站发送下载历史或登录信息。
